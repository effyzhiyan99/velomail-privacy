VeloMail AI Privacy Policy

Effective Date: June 9, 2026

VeloMail AI is a Chrome extension that helps users process Gmail messages by generating suggested replies, extracting calendar event details, and creating downloadable calendar files.

Information We Process

VeloMail AI may process the visible Gmail email content selected or opened by the user in order to provide its core features. This may include email text, sender and recipient context visible in the email thread, dates, times, locations, and event details contained in the email.

VeloMail AI may also store extension settings locally in the browser, such as the user’s access key and basic preferences, so the user does not need to re-enter them each time.

How We Use Information

We use information only to provide the extension’s user-facing features, including:

  • Generating suggested email replies
  • Extracting calendar event details
  • Creating downloadable .ics calendar files
  • Displaying the VeloMail panel inside Gmail
  • Saving local extension settings

Data Sharing

VeloMail AI may send relevant email content to an AI service provider only when needed to generate a suggested reply, extract calendar details, or produce next steps requested by the user.

We do not sell user data. We do not use user data for advertising. We do not use user data to determine creditworthiness or for unrelated purposes.

Data Storage

VeloMail AI stores basic extension settings locally in the user’s browser. Email content is processed only as needed to provide the requested feature. VeloMail AI does not intentionally store full Gmail message content on its own servers.

User Control

Users can remove locally stored extension settings by uninstalling the extension or clearing the extension’s stored data in Chrome.

Limited Use Disclosure

VeloMail AI’s use and transfer of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.

Security

We use reasonable technical measures to protect user data and limit processing to the extension’s stated functionality.
